🎬 CinemaTrack

📌 Описание проекта

CinemaTrack — это веб-приложение для ведения личного списка фильмов. Сервис позволяет пользователю удобно сохранять информацию о фильмах, которые он планирует посмотреть или уже посмотрел, а также хранить к ним заметки и постеры. Приложение помогает структурировать список фильмов и быстро управлять им через простой интерфейс.

🚀 Возможности

* Регистрация и авторизация пользователей
* Создание личного аккаунта с индивидуальным списком фильмов
* Добавление фильмов с названием и описанием
* Загрузка постера фильма (изображения)
* Разделение фильмов по статусу: «хочу посмотреть» / «просмотрено»
* Возможность удаления фильмов из списка
* Просмотр всех добавленных фильмов в удобном интерфейсе
* REST API для получения и управления данными о фильмах
